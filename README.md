# AutoClick

Grava movimentos, cliques (esquerdo/direito/meio) e rolagem do mouse e reproduz.

## Instalação
    pip install -r requirements.txt

## Uso
Dê dois cliques em `iniciar.bat` (ou `python autoclick.py`).

| Tecla | Ação |
|-------|------|
| F9    | Iniciar / parar gravação |
| F10   | Reproduzir |
| Esc   | Parar reprodução/gravação |

- **Repetições**: 0 = infinito (pare com Esc).
- **Velocidade**: 2 = duas vezes mais rápido, 0.5 = metade.
- **Salvar/Abrir**: guarda a gravação em `.json` para reutilizar.

Dica: use os atalhos (F9) em vez dos botões da janela, assim o clique no botão não entra na gravação.
